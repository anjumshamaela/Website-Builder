# AI SaaS Website Builder

AI-powered website generation platform built using the MERN stack.

## Features
- AI website generation from prompts
- JWT Authentication
- Stripe payment integration
- Credit-based usage system
- Responsive UI
- One-click deployment

## Tech Stack
- React.js
- Tailwind CSS
- Framer Motion
- Node.js
- Express.js
- MongoDB
- Stripe API

## Deployment
Hosted on Render Cloud
